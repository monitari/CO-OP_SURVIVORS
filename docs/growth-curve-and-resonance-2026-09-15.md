# 성장 곡선 · 테크 게이트 · 공명 구현

## 무기: 초반 가볍게, 후반 무겁게

카드 값이 런 내내 같아서(화력 ×1.28, Lv.6 이후 ×1.126) 무기가 강해지는 구간이 초반에 몰려 있었고, 최종 무기는 마지막 3분의 1을 12.6%짜리 카드로 보냈다. 진화하면 카탈로그 수치로 초기화되어 그 전에 산 화력 카드도 버려졌다.

`WeaponGrowth`(scripts/systems/weapon_growth.gd)가 카드 값을 한곳에서 정한다.

| 단계 | 화력 | 속도 | 고유 강화 |
|---|---:|---:|---:|
| 시작(테크 없음) | ×1.16 | ×0.95 | ×0.8 |
| 테크 | ×1.26 | ×0.91 | ×1.0 |
| 최종 무기 | ×1.30 | ×0.89 | ×1.35 |

- 시작 피해 배율 0.68 → 0.62.
- 진화 시 기본 무기에서 키운 피해·쿨다운의 35%를 이어받는다.
- 최종 무기도 해당 필드가 있으면 원래 무기의 고유 강화를 받는다(없는 필드를 새로 만들지 않는다 — 사건의 지평선에 사거리 38이 생기던 것을 막는다).

## 테크: Lv.3에 고르고, 강화 값을 정한다

- 새 무기는 테크 없이 시작, **Lv.3에서 테크 손패**가 열린다. 테크 전에는 레벨이 오르지 않는다(상자 포함). 테크가 하나뿐인 무기는 Lv.3이 되는 순간 자동 선택.
- 테크 선택은 성장 손패 하나를 쓰므로 **테크의 첫 특화 축을 한 번 무료로 강화**한다. 이게 없으면 무기마다 카드가 한 장씩 더 들었고, 측정상 한 판의 진화 수가 3분의 1 줄었다.
- 특화 축 ×1.3 / 나머지 ×0.75(축 3개 테크는 ×1.15/×0.85, 균형 테크는 전부 ×1.0). 정수 특화 강화는 +1에 피해 4~8%.
- 테크 때문에 죽던 고유 강화를 테크 전용 강화로 교체: 과부하 → 낙뢰 폭심(착탄 폭발), 월식 → 월식 잔상(0.24초 뒤 재베기), 심판 → 창 폭, 혜성 추적·작은 태양 → 추가 관통. 봉쇄 정원은 `매설 수 + 3`.
- 새 무기 카드는 무기당 한 장(예전엔 테크 수만큼 같은 무기가 깔렸다).

### 보물 칸 예약

테크가 늦게 정해지면서, 필요한 보물을 알기 전에 칸이 무작위 보물로 차 **진화할 수 없는 무기**가 생겼다(측정 런에서 심판의 창 Lv.12·처형자의 표식 없음). 이제 남은 칸이 "누락된 테크 보물 + 보유 보물로 해결되지 않는 테크 미정 무기" 이하이면 무작위 새 보물을 내놓지 않는다. 테크 카드는 필요 보물을 이미 가졌으면 `보유`(추천 +22), 칸이 없으면 `칸 없음`(−30)을 표시한다.

## 보물

단계 가중치 `[0.6, 0.75, 0.9, 1.0, 1.1, 1.25, 1.4, 1.55, 1.7, 1.85]`. 합계는 Lv.7에서 예전 평평한 사다리와 같아지고 Lv.10에서 21% 높다. Lv.4(진화 조건)까지는 3.25배(예전 4배).

정수 보물(발사체·관통·행운·기사회생)과 **진행 속도 보물(성장·자석·탐욕·사냥꾼 방울)은 평평하게** 둔다. 진행 보물까지 가중치를 걸었더니 초반 레벨업이 느려져 한 판 전체 카드 수가 줄었다.

## 공명

한 번의 즉발 타격으로 대신하던 공명을 설명대로 구현했다: 지속 틱(`resonance_ticker.gd`, 런과 함께 멈추고 `clear_transients`가 취소), 목표 선택(보스 > 엘리트 > 체력, 사분면별 최근접, 밀집 지점), 착탄 콜백(`HomingProjectile.on_impact`), 명중 둔화(`slow_on_hit`), 실제 끌어당김(중력 필드).

버그: 주인 없는 공명 시전(`current_source_player = -1`)이 `players[-1]`로 P2의 관통을 빌려 썼다.

군집(13×11 격자)과 단일 대상에 3초간 준 피해, 수정 전 대비:

| | 군집 | 단일 |
|---|---:|---:|
| 폭풍의 핵 | 2.02× | 0.97× |
| 절대영도 | 1.77× | 1.50× |
| 성혼 궤적 | 1.76× | 1.00× |
| 황혼 추적 | 1.71× | 1.09× |
| 폭풍 유성군 | 1.70× | 1.26× |
| 추적 뇌광 | 1.41× | 1.73× |
| 기존대로 동작하던 5종 | 1.00× | 1.00× |
| **전체 군집 합** | **1.19×** | |

첫 구현은 군집 합 1.31×(폭풍의 핵 4.8×, 유도 폭격 4.1×, 혜성우 4.0×)여서 틱 수·관통·피해를 낮췄다. 침묵한 무기 레벨당 공명 보너스 0.11 → 0.15.
