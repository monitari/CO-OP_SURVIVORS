# 성장과 보상 개편

- 영구 성장 12종: 기존 6종에 방어, 재생, 치명, 범위, 지속, 구조 추가. 6종씩 페이지 전환.
- 초기화는 별도 확인 후 구매 비용 전액 환급. 발견 기록 보존, 저장 실패 시 재화와 단계 모두 복원.
- AI 성장 선택은 점수 기반 확률 추첨. 캐릭터 후보 5종을 순환하므로 같은 최적 조합에 고정되지 않음.
- 캐릭터 미리보기는 별도 SubViewport, 공간 그리드, 연습 적으로 실제 WeaponController를 실행. 연습 적은 게임의 적 그룹에 등록하지 않음.
- AI/LAN 성장 화면은 내 카드 중앙, 동료 선택은 위쪽 구석. 전체 능력치는 내 상세 정보와 동료 요약으로 구성.
- 일반 성장 카드는 3장부터 시작하며 행운에 따른 독립 추가 추첨으로 최대 6장. 테크 선택은 제공 가능한 실제 후보 수 유지.
- 행운은 상자 보상 분포와 특수 필드 아이템 가중치에도 반영. 상자는 최대 8장을 두 줄 카드로 표시하고 중복 하단 목록 제거.
- 카드 평가: 👍 추천 / 👎 비추천 / — 보통. 현재 빌드 기준 이유와 효과 미리보기를 표시하며 긴 상자 설명은 마우스를 올려 확인 가능.

검증: 영구 성장 저장·환급·실패 복원, 확률 표본, AI 선택 다양성, 12종 무기 실행, 6장 성장/8장 상자, LAN 클라이언트 시점 및 화면 캡처.
