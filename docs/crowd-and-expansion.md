# 군중 최적화와 옥상 확장

## 전투 성능

밀집 셀의 전원 쌍 비교를 적당 최대 12개 이웃 표본 비교로 변경했다. 물리 프레임마다 표본을 회전하며 플레이어와의 겹침은 기존처럼 전부 처리한다. 따라서 아주 빽빽한 군집은 여러 프레임에 걸쳐 풀린다. 적 수 제한은 줄이지 않았다.

620마리 단일 셀 스트레스 검사에서 전체 쌍 비교 약 408ms, 제한 비교 약 6.8ms를 측정했다. 전체 프레임 시간이나 실제 FPS가 아닌 분리 처리만의 측정이다. 최근접 표적 검색의 중간 배열과 피격 반짝임 중 불필요한 체력 표시 다시 그리기도 줄였다.

격자 검색은 적이 존재하는 영역 안으로 제한하여 초대형 범위가 빈 셀 수백만 개를 탐색하지 않게 했다. 약 26분 가속 안정성 검사는 최대 618마리와 12종 적을 처리하고 통과했다. 체력·자석을 강화한 검사이며 보스 전부 격파를 검증한 결과는 아니다.

## 화면

이름과 체력은 한 줄, 시계 중심은 x=640이다. 사슬 바 두 개는 156px씩 가로로 배치하고 큰 HUD 배경을 제거했다. 알림은 우측 하단 최대 4개, 최신 항목이 아래에 오며 3초 후 0.65초 동안 사라진다. 메뉴에서는 숨긴다. RUN SNAPSHOT은 ‘이번 산책’의 시간·레벨·처치·사슬 내구 4개 항목으로 바꿨다.

## 새 수호대와 위협

- 미캉 / 생선 부메랑: 왕복 각 구간당 한 번 적중. 투척 수와 거리를 강화한다.
- 스즈 / 방울 파동: 퍼지는 가장자리에 닿은 적에게 한 번 적중. 거리와 피해를 강화한다.
- 지그재그 도둑쥐, 옆으로 움직이며 쏘는 말벌, 피해를 28% 줄이는 고슴도치, 돌진 두더지, 세 갈래로 쏘는 부엉이를 120초부터 단계적으로 해금한다.
- 2·4번째 보스는 부엉왕이다. 예고 후 부채꼴 3발과 방사형 8발을 쏜다.

신규 그림은 독립 SVG로 만들었다. 기존 아틀라스는 중앙 연결 영역과 여백을 계산해 정사각형 규격으로 표시한다. 조금 어긋난 셀 경계는 6% 확장하여 귀·무기 끝 잘림을 줄인다.

## 판단 정보

난이도는 기존 생존·이동·범위 평가에 무기 조작 부담과 재생을 추가하여 별 1~5개로 표시한다. 사람 플레이 측정이 아닌 설계 수치 기반 추정이다. 추천 화력의 범위 이득은 유한한 군중 밀도를 고려해 제한하고 다중 광선은 중복 적중에 따른 수익 감소를 반영했다. 비추천은 상대 점수와 절대 점수가 모두 낮을 때만 표시한다.
