# AI · 화분 · 사용자 시점 개편

- 게임 시작 → AI / 로컬 멀티 / LAN 멀티 선택. AI와 로컬은 별도 참가 입력 없이 캐릭터 선택으로 이동.
- AI는 1.4초 동안 후보를 비교하고 조합을 보완하는 캐릭터를 선택. 사용자 선택 변경 시 다시 판단.
- 이동은 탐색, 보급품, 무기 사거리, 구조를 우선순위로 판단. 사슬은 넓게, 근접 장비는 가까이, 원거리 장비는 거리를 두고 싸움. 체력·사슬 내구가 낮으면 결속 거리를 줄임. 장비 변경 즉시 목표 재평가.
- 화분: 최대 12 → 5, 구역당 2~3 → 1, 구역 생성 확률 46% → 36%, 구역 경계 여백으로 최소 480px 간격. 파괴 시 1개 보상은 유지.
- 온라인 네트워크 슬롯은 유지하고 표시만 사용자 기준 P1 / 동료 P2로 변환. HUD, 머리 위 번호, 성장 카드, 선택·상세 정보에 적용.
- AI/온라인 선택 화면과 성장 화면은 동료 정보를 축소. 남는 선택 공간에 실제 ChainPlayer 걷기 미리보기. 같은 화면을 쓰는 로컬 2인의 캐릭터 선택·상세 정보는 두 사람 조작을 유지.

검증: autonomy_flow_test, coop_rework_test, online_state_test, crowd_test, ux_flow_test, lobby_flow_test. 실제 렌더러 캡처는 .godot_runtime/autonomy-*.png. 온라인 검증은 상태/표시 슬롯 테스트이며 두 PC를 연결한 수동 LAN 검증은 별도.
