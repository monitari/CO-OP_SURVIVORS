# 비평 반영 · 2026-09-06

## 변경

- A-1: 예정된 보스·정예·조우의 필요 자리를 먼저 계산한다. 부족하면 가장 먼 일반 적부터 보상 없이 회수한다. 일반 웨이브가 예약 자리를 사용하지 못하며, 총 620마리 제한은 유지된다. 확보할 수 없는 조우는 소비하지 않고 재시도한다. 상한에서도 타이머는 진행한다.
- B-1: 초반 접촉 피해의 선형 상승을 완만한 제곱 곡선으로 교체했다. 시작 배율 50%, 원래 피해에 도달하는 시점 약 87초는 유지한다. 예를 들어 43초에 생성된 적은 기본 피해의 약 63%를 준다.
- B-2: 접촉 반경 근처 3~6마리부터 포위 가중치가 적용된다. 90~240초에 걸쳐 활성화하며 최대 접촉 피해 +60%. 투사체·사슬 공격은 가중하지 않는다. 피격 무적 0.55초 및 회피·대시·아이템 무적은 유지한다. 붉은 발밑 테두리로 압박을 표시한다.
- B-3: 120초 이후 등장하는 도둑쥐는 0.75초 예고 → 1.5초 추격 질주 → 휴식으로 움직인다. 회전 속도가 제한되어 방향 전환/대시로 대응할 수 있다. 두더지는 기존 직선 돌진을 유지한다. 말벌·부엉이·두더지는 이동 입력을 바탕으로 0.65초 앞을 조준하고 사격/돌진 예고 후에는 고정한다.
- C-2: 비추천 조건은 절대점수 38 이하와 최고점의 60% 이하를 동시에 만족할 때다. 추천과 겹치지 않으며 모든 카드를 비추천으로 만들지 않는다. 최고점을 억지로 추천하지는 않는다.
- D-1: 에코(아비시니안)·라떼(노르웨이숲) 초상화를 기존 10마리의 PNG 아틀라스 스타일에 맞춰 교체했다. 기존 SVG 원본은 보존했다.
- D-3: 보스 이름·체력을 화면 상단 y=100~122의 한 줄에 통합했다. 불투명 패널, 상단 목표 칸의 중복 이름, 보스 개체의 작은 체력바를 제거했다. 등장 알림은 잠시 표시된 뒤 사라진다.
- D-4: 고슴도치의 가시, 비행 적의 넓은 날개, 두더지·쥐의 전방 실루엣과 후방 궤적을 채워진 도형으로 표현한다. 이동 방향에 따라 회전하며 기본 실루엣은 매 프레임 다시 그리지 않는다.
- 필드 아이템: 무적 육각 보호막, 광란 회전 불꽃, 시간 정지 시계·정지 표식 및 남은 시간 호를 추가했다. 공유 노드 하나를 사용하고 적 정지 표식은 최대 24개다. 만료 시 지운다.

## 검증

- `critique_regression_test.gd`: 620마리에서 보스 5회, 정예, 조우 5종의 전체 인원 생성 및 상한 유지; 포위 가중치; 아이템 무적 유지; 실제 카드의 비추천 발생; PNG 투명도; 이펙트 만료.
- 별도 격리 실험: 공격/대시 없는 속도 288 캐릭터가 반경 340의 원을 60초간 이동하고 적 6마리가 추격. 기본 추적자 피해 43.2, 개편 도둑쥐 피해 403.2. 체력은 측정용으로 높였다. 전체 런의 생존율을 뜻하지 않는다.
- 실제 렌더러 캡처: 초상화 선택창, 보스 강타 HUD, 신규 적, 아이템 연출 확인.
- 조우, 성장 곡선/회수, 카드, 레이아웃(335개 컨트롤), UI 흐름, 기존 리뷰 회귀, 신규 콘텐츠, 적 다시 그리기, 무기 런타임 테스트 통과.
- 620마리 겹침 해소 단독 측정: 기존 전체 쌍 339.34ms, 제한 탐색 9.73ms. 전체 프레임 시간이나 GPU 성능 측정은 아니다.
- 초반 테스트는 정상 체력·일반 자력·이동/대시/자동 선택을 사용한다. 중립 카드만 나온 경우에도 최고점 카드를 선택하도록 테스트 자동 조작을 수정했다. 90초를 채워야 통과하도록 판정도 강화했다.
- 초반 결과: 라이라+볼타(시드 20260905) 90초·다운 0·96킬·레벨 3·체력 69/80, 이그니스+네베(시드 20260906) 90초·다운 0·93킬·레벨 3·체력 126/126. 전자는 중립 카드 자동 선택 수정 후 재실행한 결과다.

25분/40분 전체 런과 모든 66개 캐릭터 조합의 생존율은 재측정하지 않았다. 포위 가중치와 질주는 이번 검증에 기반한 1차 조정이며, 장기 런의 체감까지 확정한 것은 아니다. 테스트 종료 시 일부 기존 ObjectDB 해제 경고 및 샌드박스 인증서 읽기 경고가 남아 있다.
