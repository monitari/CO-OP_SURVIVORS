# 네온 성장 화면

첨부 시안을 바탕으로 기존 무기·고양이 아이콘에 코드로 그린 네온 테두리, 발바닥 장식, 선택 강조를 적용했다.

- 내 카드가 중앙을 차지하며 3장은 크게, 4~6장은 너비와 간격을 조절한다.
- 동료가 선택한 카드의 아이콘, 이름, 효과 요약, 확정 여부는 오른쪽 위 패널에 표시한다. 전체 설명은 툴팁으로 확인한다.
- 카드 본문은 실제 성장 전후 수치, 하단은 기존 빌드 평가와 예상 화력 변화로 구성한다. 테크 카드의 긴 설명은 작은 아이콘과 넓은 본문 영역을 사용한다.
- 체력·공유 레벨·시간·사슬 HUD를 유지하고, 내 체력은 청록색, 동료는 보라색으로 표시한다.
- 클릭, 우클릭 상세 보기, 키보드·패드 선택, 재추첨과 로컬 플레이어 차례 전환을 유지한다.
- 소유 색은 나의 밝은 청록과 동료의 주황으로 분리한다. 무기 자체의 속성색과 소유 색을 섞지 않는다.
- 카드 선택 시 위치를 0.18초 동안 보간하고, 캐릭터 변경 시 새 초상화가 부드럽게 확대된다.
- 플레이어 HUD는 초상화 배경판과 개인 레벨을 제거한다. 장비는 보유한 아이콘만 표시하며 빈 슬롯과 빈 보물 행은 숨긴다.

주요 구현: scripts/ui/neon_growth_ui.gd, scripts/ui/neon_frame.gd.
검증: tests/neon_growth_test.gd에서 3장/6장, 클릭 확정, 재추첨, LAN 클라이언트 시점, 로컬 차례 전환과 캡처를 확인한다.
