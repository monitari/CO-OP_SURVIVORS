# 달빛 옥상 · 간식 수호대

달빛 옥상 야경을 종이 질감과 콜라주로 엮은 **스크랩북** UI입니다. 배경과 이미지 타이틀은 빈티지 인쇄물의 색과 질감을 사용하고, 메뉴·카드·대화창은 크림색 종이와 잉크 표현으로 통일합니다. 초상과 메인 화면 스냅은 흰 테두리 안의 **정사각 사진**에 담습니다. 선택된 조각은 카드 바깥의 마커 선으로 표시하며 제목, 주요 수치, 설명, 조작 안내 순으로 정보의 위계를 둡니다.

- 종이 위 글자는 잉크(`INK`, `MUTED`, `P1_INK`/`P2_INK`, `GOLD_INK`), 야경이나 전투 위에 바로 놓인 글자는 밝은 색(`CREAM`, `NIGHT_MUTED`)을 씁니다. P1 청록 / P2 주황의 밝은 원색은 체력 막대처럼 전투용 표시에만 씁니다.
- 글꼴은 역할로 나눕니다. 종이 위에서 천천히 읽는 글(제목, 카드 이름, 설명, 대사)은 **Griun 한글 고운체**, 전투 중 한눈에 읽어야 하는 수치(상단 HUD 띠, 시계, 체력·경험치 막대, 보스 바, 피해 숫자, 화면 밖 지시자, 우하단 알림 로그)는 **Jua**를 씁니다. 고운체의 가는 획은 13~16px 야경 위에서 사실상 읽히지 않으므로, HUD에는 쓰지 않습니다. 두 글꼴에 없는 기호(`·`, 화살표, 줄표 등)와 빠진 한글 음절은 **Memoment 꾹꾹**이 대신 그립니다.

최우선 제작 규칙은 [UI 제작 및 이미지 생성 지침](ui-generation-guidelines.md)입니다. 이 문서는 런타임 구현 세부사항을 다루고, 이미지 시안의 레이아웃·정렬·컴포넌트 규칙은 해당 문서의 하드 제약을 따릅니다.

- `scripts/ui/cat_theme.gd`: 종이·잉크·밤하늘 색, P1 청록 / P2 주황과 그 잉크 톤, 종이 조각(`paper`)·사진(`photo`)·버튼 스타일. 밝고 채도 낮은 색으로 `surface()`를 부르면 자동으로 종이 조각이 됩니다.
- `scripts/ui/neon_frame.gd`: 이름은 예전 그대로지만 이제 스크랩북 장식입니다. 모서리 마스킹 테이프, 선택 시 마커 테두리, 발바닥 도장을 그립니다.
- `scripts/ui/polaroid.gd`: 제목 화면의 고양이 정사각 폴라로이드(밤하늘 사진, 테이프). 제목 화면에서는 캡션 없이 사용합니다.
- `scripts/ui/editorial_ui.gd`: 로비, 초상 기반 캐릭터 목록, 아이콘 능력치, 성장 카드, 결과 통계, 설정 행의 레이아웃과 표시값. 게임 규칙 및 입력은 `main.gd`에 유지합니다.
- `scripts/ui/cat_panel.gd`: 작은 발바닥 인장, 모달/전투 HUD 패널, 야경 배경. 코드로 그리므로 해상도별 이미지가 필요하지 않습니다.
- `scripts/main.gd`: 모든 UI는 `ThemeHost`의 한국어 폰트를 상속하고, 전투 수치만 `CatTheme.READOUT`으로 덮어씁니다. `CombatHUD`는 로비와 캐릭터 선택에서 숨깁니다.
- 아틀라스는 `assets/atlases/`, 개별 스프라이트는 `assets/sprites/`에 있고, 생성 원본과 프롬프트 기록은 저장소 루트의 `art/`에 있습니다(`.gdignore`로 임포트에서 제외).

장식은 입력을 받지 않습니다. 전투에서는 밝은 P1 청록 / P2 주황을 유지하고 적·과부하 위험 색상을 구분합니다. 선택 카드는 확대하지 않고 테두리로 강조합니다. 성장 카드는 적용 범위 / 종류 / 이름 / 현재→변경 수치 / 추천 배지 순으로 읽고, 행운의 네 번째 선택까지 한 줄 안에서 겹치지 않게 배치합니다. 선택을 마친 동료의 작은 카드 묶음 대신 우측 상단 요약 메모에 선택 결과와 추천 이유를 표시합니다. 카드 클릭은 포커스만 옮기며 각 플레이어의 **선택 확정** 입력이 잠금을 담당합니다. 하단 장비 줄은 포커스된 카드의 대상 슬롯과 다음 레벨 또는 신규 슬롯을 함께 표시합니다.

검증: `tests/cat_theme_test.gd`에서 전체 모달 테마·폰트 상속·10종 캐릭터 및 카드/일시정지 글자 잘림, 합성 정보, 컨트롤러 연결 안내와 아이콘 영역을 검사합니다. `tests/visual_capture.gd`는 로비부터 결과까지의 화면과 적 7종 갤러리를 `.godot_runtime/`에 저장합니다.

## 적과 맵

메인 메뉴는 1920×1080 스크랩북 옥상 배경 위에 이미지로 만든 타이틀 로고를 놓습니다. 같은 배경과 로고를 플레이 방식 하위 화면과 LAN 로비에도 사용합니다. 로고는 왼쪽 게임 시작 카드 바로 위에 정렬하고, 그 아래 종이 카드 다섯 장을 세로로 쌓습니다(게임 시작이 가장 크고, 제작진·종료는 한 단계 작게). 카드마다 1° 안팎으로 기울이되 간격은 12px 하나로 맞춥니다. 커서가 놓인 카드는 금색으로 칠해지고 오른쪽으로 살짝 빠져나오지만 마우스 클릭 영역은 움직이지 않습니다. 오른쪽에는 이그니스·네베·테라·노바가 여러 표정과 동작으로 등장하는 캡션 없는 정사각 스냅 네 장을 서로 다른 높이·크기·각도로 흩어 놓습니다. 마우스 hover와 키보드/패드 커서는 같은 선택 상태를 사용합니다. 캐릭터 선택은 AI·로컬·온라인 모두 동일한 두 개의 560×376 패널을 유지하며, 큰 초상화와 네 개의 핵심 능력치를 먼저 보여 줍니다. 추가 능력치와 설명은 TAB/X 비교 화면에서 같은 패널 안에 표시하고, 준비 버튼과 8px 이상 떨어뜨립니다.

`scripts/entities/enemy_art.gd`에서 기존 행동 ID를 유지하며 원본 벡터 도형을 그립니다. 이동 방향을 따라 회전하고 피격 시 밝아집니다. 추가적인 매 프레임 재그리기는 하지 않습니다.

| 행동 ID | 표현 | 역할 |
| --- | --- | --- |
| chaser | 간식 도둑 쥐 | 기본 추적 |
| swarm | 벼룩 | 빠른 무리 |
| charger | 경비견 | 직선 돌진 |
| shooter | 까마귀 | 원거리 투척 |
| chain_hunter | 너구리 | 사슬 중앙 추적 |
| bulwark | 철통 너구리 | 느린 탱커 |
| brute | 폭주 청소 로봇 | 보스 강타·돌진·폭주 |

`scripts/entities/arena_floor.gd`는 엇갈린 옥상 포장, 배수로, 급식 매트, 식물 화분, 상자, 환기구를 고정 배치합니다. 소품은 장식이며 충돌 장애물이 아닙니다. 플레이어는 선택 화면과 같은 고양이 아틀라스를 사용합니다. 이번 개편은 피해량·속도·스폰·충돌 반경을 변경하지 않습니다.
