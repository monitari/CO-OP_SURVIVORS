# 달빛 옥상 · 간식 수호대

달빛 옥상 야경과 짙은 네이비 패널을 사용하는 협동 게임 UI입니다. 제목, 주요 수치, 설명, 조작 안내 순으로 정보의 위계를 둡니다.

최우선 제작 규칙은 [UI 제작 및 이미지 생성 지침](ui-generation-guidelines.md)입니다. 이 문서는 런타임 구현 세부사항을 다루고, 이미지 시안의 레이아웃·정렬·컴포넌트 규칙은 해당 문서의 하드 제약을 따릅니다.

- `scripts/ui/cat_theme.gd`: 네이비·크림·달빛 금색, P1 청록 / P2 주황, 공통 패널 및 9분할 스타일.
- `scripts/ui/editorial_ui.gd`: 로비, 초상 기반 캐릭터 목록, 아이콘 능력치, 성장 카드, 결과 통계, 설정 행의 레이아웃과 표시값. 게임 규칙 및 입력은 `main.gd`에 유지합니다.
- `scripts/ui/cat_panel.gd`: 작은 발바닥 인장, 모달/전투 HUD 패널, 야경 배경. 코드로 그리므로 해상도별 이미지가 필요하지 않습니다.
- `scripts/main.gd`: 모든 UI는 `ThemeHost`의 한국어 폰트를 상속합니다. `CombatHUD`는 로비와 캐릭터 선택에서 숨깁니다.
- 아틀라스는 `assets/atlases/`, 개별 스프라이트는 `assets/sprites/`에 있고, 생성 원본과 프롬프트 기록은 저장소 루트의 `art/`에 있습니다(`.gdignore`로 임포트에서 제외).

장식은 입력을 받지 않습니다. 전투에서는 밝은 P1 청록 / P2 보라를 유지하고 적·과부하 위험 색상을 구분합니다. 선택 카드는 확대하지 않고 테두리로 강조합니다. 성장 카드는 적용 범위 / 종류 / 이름 / 현재→변경 수치 / 추천 배지 순으로 읽고, 행운의 네 번째 선택은 겹침 없는 2×2 그리드로 배치합니다. 카드 클릭은 포커스만 옮기며 각 플레이어의 **선택 확정** 버튼이 잠금을 담당합니다. 하단 장비 줄은 포커스된 카드의 대상 슬롯과 다음 레벨 또는 신규 슬롯을 함께 표시합니다.

검증: `tests/cat_theme_test.gd`에서 전체 모달 테마·폰트 상속·10종 캐릭터 및 카드/일시정지 글자 잘림, 합성 정보, 컨트롤러 연결 안내와 아이콘 영역을 검사합니다. `tests/visual_capture.gd`는 로비부터 결과까지의 화면과 적 7종 갤러리를 `.godot_runtime/`에 저장합니다.

## 적과 맵

메인 메뉴는 중앙 로고·마스코트 아래에 큰 시작 버튼을 두고, 영구 성장·설정·제작진·종료를 2×2 보조 행동으로 배치합니다. 마우스 hover와 키보드/패드 커서는 같은 선택 상태를 사용합니다. 캐릭터 선택은 AI·로컬·온라인 모두 동일한 두 개의 560×376 패널을 유지하며, 큰 초상화와 네 개의 핵심 능력치를 먼저 보여 줍니다. 추가 능력치와 설명은 TAB/X 비교 화면에서 같은 패널 안에 표시하고, 준비 버튼과 8px 이상 떨어뜨립니다.

`scripts/entities/enemy_art.gd`에서 기존 행동 ID를 유지하며 원본 벡터 도형을 그립니다. 이동 방향을 따라 회전하고 피격 시 밝아집니다. 추가적인 매 프레임 재그리기는 하지 않습니다.

| 행동 ID | 표현 | 역할 |
| --- | --- | --- |
| chaser | 간식 도둑 쥐 | 기본 추적 |
| swarm | 벼룩 | 빠른 무리 |
| charger | 경비견 | 직선 돌진 |
| shooter | 까마귀 | 원거리 투척 |
| chain_hunter | 너구리 | 사슬 중앙 추적 |
| bulwark | 철통 너구리 | 느린 탱커 |
| brute | 폭주 청소 로봇 | 보스 강타·돌진·폭주 |

`scripts/entities/arena_floor.gd`는 엇갈린 옥상 포장, 배수로, 급식 매트, 식물 화분, 상자, 환기구를 고정 배치합니다. 소품은 장식이며 충돌 장애물이 아닙니다. 플레이어는 선택 화면과 같은 고양이 아틀라스를 사용합니다. 이번 개편은 피해량·속도·스폰·충돌 반경을 변경하지 않습니다.
