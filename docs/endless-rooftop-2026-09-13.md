# 무한 옥상 원근 렌더링

실제 런에도 화면 위쪽은 좁아지고 아래쪽은 넓어지는 완만한 원근감을 적용한다.
높이 표현은 기존 RooftopSpace.LIFTED와 Y 정렬을 사용하고, 전장 전체를
EndlessRooftopView의 SubViewport에서 그린 뒤 하나의 원근 변환으로 표시한다.
캐릭터, 무기, 적 예고선, 전리품이 모두 같은 변환을 거치므로 별도의
시뮬레이션 좌표 교환이나 카메라 이동에 따른 물리 위치 변경이 없다.
HUD와 메뉴는 원래 뷰포트에 남는다.

- 세로 기울기 0.86, 원근 계수 0.18. 작은 스프라이트의 변형을 줄이는 강도다.
- 화면보다 가로·세로 1.5배 넓게 렌더링하여 원근 변환 후 모서리까지 채운다.
  이는 같은 출력 해상도 대비 2.25배 픽셀의 전장 렌더 타깃 비용을 가진다.
- 바닥 생성 반경은 확대/축소와 화면 크기에 따라 늘어나며 일정 간격으로만 갱신한다.
- 화면 밖 적 안내와 화면 청소 아이템의 범위도 동일한 투영/역투영을 사용한다.
- 높은 배관은 실제 런의 장식 목록에서 빼고, 낮은 소품을 72% 크기로 배치한다.
  배치 빈도와 대비를 낮추고, 플레이어 및 두 플레이어 사이의 주변에서
  알파가 0.10까지 부드럽게 감소한다. 멀어지면 0.68로 복원된다.
- 장식은 이동·공격을 차단하거나 보상을 지급하지 않는다.
  WaveDirector의 파괴 가능한 보급 화분은 별도다.

검증: tests/endless_rooftop_test.gd
원근/역원근 일치, 전투 전체의 동일 뷰포트 사용, HUD 분리,
소품 투명도 복원, 좌표 (120000, -90000) 및 0.45배 축소에서 바닥 덮임과
장식 수 제한을 검사한다. --capture로 실제 렌더러 캡처를 저장한다.

실행 결과: ENDLESS_ROOFTOP_PASS, ONLINE_STATE_PASS, SMOKE_TEST_PASS,
SHOWCASE_PASS, FRAME_BUDGET_PASS. 620마리의 headless 시뮬레이션 틱 평균은
5.61ms였다. 이 수치는 GPU 렌더링 비용이나 실제 FPS 측정값은 아니다.
pacing_and_world_test의 무한 바닥 검사는 통과했으나 기존 캐릭터 선택
라벨에 최종 형태/공명/재료 문구를 요구하는 검사 5건은 실패했다.
해당 캐릭터 선택 UI와 문구는 이번 렌더링 작업에서 수정하지 않았다.
