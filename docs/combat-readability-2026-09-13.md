# 전투 화면과 압박 개편

- 일시정지: 멈춘 전투 위에 380px 메뉴. 기본은 계속/설정/메뉴/종료이며 장비 상세를 별도로 열 수 있음. 설정은 접힌 페이지로 이동, 종료 확인 유지.
- 처치 회복: 18킬마다 각 8 HP를 주던 자동 보상 제거. 처치 경험치, 회복 아이템, 장비 회복, 보스 체크포인트 보상 유지.
- 생성: 일반 적 반경 610~760 → 900~1080. 일반 무리는 940~1020 거리에서 한 방향으로 진입하고 좌우 간격은 64 → 36px로 감소. 무리 크기 2 + floor(wave / 3), 주기 1.2초에서 최저 0.1초까지 감소. 휴식 9 → 6초. 특수 포위·돌진·대범람 생성 거리도 확대. 개체 상한 620 및 1500px 제거 반경 유지.
- HUD: 무기/보물 모두 40px 정사각형. 등급은 숫자만, 일반 무기 테두리는 실제 재사용 시간에 따라 은색으로 충전. 공명 무기는 I~VI 및 금색으로 동일 공명 구분. 보물·상시 냉기 효과는 순환하는 테두리. 일시정지 시 순환도 멈춤.
- 온라인: 호스트의 무기 재사용 시간과 공명 상태를 스냅샷으로 전달. 네트워크 슬롯은 유지하고 노출 문구/머리 위 표식/성장/연출/디버그 표기는 나와 동료로 변경.

검증: combat_readability_test, wave_and_scaling_test, online_state_test, crowd_test, ux_flow_test, review_regression_test, cat_theme_test, layout_test, frame_budget_test.
실제 렌더러 캡처: .godot_runtime/readability-{equipment,pause,settings,confirm}.png.
620마리 CPU 시뮬레이션 평균 4.75ms, p99 7.07ms (렌더링 FPS 측정은 아님).
