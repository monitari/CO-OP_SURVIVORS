# UI 개편 · 2026-09-13

## 성장 선택

- P1/P2 각각 겹친 부채꼴 유지. 3장과 4장 모두 카드 크기 190×306, 본문 16px을 유지하고 펼침 간격만 조절한다.
- 마우스 또는 기존 키보드·패드 이동으로 가리킨 카드는 수직으로 서서 맨 앞으로 올라온다. 클릭은 비교, 확정은 별도 버튼이다.
- 카드 바탕은 불투명하다. 동료의 대기·확정 상태는 RGB 밝기로 구분하여 겹친 설명이 비치지 않는다.
- 전투 장면 위에는 카드와 현재 선택자의 `다시 뽑기`만 표시한다. 카드 클릭 또는 각 플레이어의 확정 키로 즉시 선택하며, 같은 카드를 다시 클릭하거나 취소 키로 되돌린다.
- 제목·상태·장비 슬롯·상세·확정·취소 패널은 성장 화면에서 숨긴다. 글자가 잘리지 않도록 4장일 때도 설명을 생략하지 않는다.

## 캐릭터와 전투

- 캐릭터 기본 화면에는 플레이 스타일, 난이도, 핵심 능력치 네 개와 시작 무기를 표시한다.
- 상세 보기 버튼 또는 TAB/패드 X로 전체 능력치와 테크·진화 재료를 확인한다. 토글은 선택이나 준비 상태를 바꾸지 않는다.
- 체력바와 숫자를 확대하고 체력 25% 이하를 색으로 강조한다. 장비 레벨은 큰 숫자로 표시하고 이름·레벨·공명 여부는 툴팁으로 제공한다.
- 화면 하단 행동 안내는 구조 → 사슬 과부하 → 거리 한계 → 체력 위험 → 내구 부족 순으로 가장 긴급한 한 가지를 보여준다. 위험이 해소되거나 선택/일시정지 화면을 열면 사라진다.
- 로비의 AI 동료 버튼을 강조하고 LAN 주소 입력칸도 공통 테마에 맞춘다.
